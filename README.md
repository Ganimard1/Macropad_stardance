# Macropad_stardance
Repo containing all the files for my macropad (3 keys, 4 leds and an oled screen)

PCB Link: https://kicanvas.org/?repo=https%3A%2F%2Fgithub.com%2FGanimard1%2FMacropad_stardance%2Fblob%2Fmain%2FPCB%2Fmacropad.kicad_pcb

PCB:
I have little to no prior experience in electronics and I wanted to change that by this macropad. Its nothing flashy or complicated. Just 3 keys, 4 leds and an oled screen
It has 3 keys as I didnt want to deal with matrices just starting out.

CASE:
I've always loved how pcbs look and wanted a completely exposed case which shows the pcb with all the soldered parts.
